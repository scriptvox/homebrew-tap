# ScriptVox Homebrew tap

```sh
brew install scriptvox/tap/scriptvox
```

On macOS this also installs FFmpeg (`ffmpeg-full`) and uv from Homebrew. ScriptVox uses them.

- ScriptVox: https://github.com/scriptvox/scriptvox
- The formula downloads the release archive from GitHub and checks its sha256.
- macOS is a preview. Its limits are in the ScriptVox README.
